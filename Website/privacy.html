About KINGDOMS LIVE

KINGDOMS LIVE is a functional Windows interactive battle game operated from Tajikistan. This policy covers the game and its website. Local simulation works; authorized TikTok LIVE production transport/access is still awaiting authorization. The legal operator name remains to be supplied: [OPERATOR LEGAL NAME REQUIRED].

Information We May Receive

An authorized LIVE provider may supply viewer display name or username, provider user identifier, LIVE interaction type, Gift identifier and name, repeat/combo information, event identifier and timestamp, and limited technical connection metadata. The game derives a team assignment and application diagnostics. Supported team-command comments may be processed when enabled; ordinary comments are ignored for gameplay. Likes may be counted in aggregate, without an enabled gameplay effect. A provider adapter must minimize event fields and exclude credentials from event metadata.

Information We Do Not Collect

KINGDOMS LIVE does not independently request or store TikTok passwords, payment card details, bank account information, browser cookies, private TikTok messages, device contact lists, precise location or unrelated profile information. It does not independently process Gift payments. Future authorized adapters may use application access credentials supplied outside published files; those are not viewer login credentials.

How Information Is Used

Information is used to spawn viewer-associated units, assign teams, process supported LIVE events, prevent duplicate events, maintain game state, diagnose connection or runtime problems, prevent abuse, and display usernames and gameplay announcements. The game does not create permanent viewer profiles, sell viewer data or use it for advertising profiles.

LIVE Interaction and Gifts

When authorized integration is available, supported Gift events may trigger entertainment actions such as Warrior, Archer, Mage, Knight, Hero or Dragon. TikTok or the applicable platform handles Gifts and payments under its own rules. The current demonstration uses local simulated events. Usernames and announcements may appear in a public stream or recording, where audiences and the streaming platform can see and retain them.

Data Retention

Viewer-to-team mappings stay in memory for the running game session and are not saved as viewer profiles. They can remain across battle rounds and reconnects; closing the game ends this session storage. Incoming normalized events are queued temporarily and removed as processed, with a queue limit of 1,024. The recent event monitor holds up to 20 rows. Deduplication retains at most 8,192 accepted event keys, evicting older keys as new events arrive. Unit-associated details remain while the game retains those units; session status fields may show the last processed event or Gift until replaced or the game closes.

Provider diagnostics use a bounded rolling file: when the active file exceeds 512 KiB, the next write replaces the previous backup and rotates the active file. There is one active file and at most one backup, each approximately 512 KiB plus the final entry. Rotation depends on file size, not age; no seven-day deletion is promised. The operator can remove local diagnostic files when no longer needed. Logs contain connection states, generic errors and unknown Gift IDs/names, not intended viewer profiles. Gift-to-action settings and Gift catalog entries persist locally until changed or deleted and do not require a viewer list. Separately created recordings, screenshots, email correspondence and hosting records follow their respective owners' or providers' retention practices.

Third-Party Services

KINGDOMS LIVE may interact with TikTok or another authorized LIVE provider, whose own privacy policies and terms apply. KINGDOMS LIVE does not control their independent processing of accounts, Gifts or payments and does not claim an official partnership. This static website is hosted by GitHub Pages. GitHub records visitor IP addresses for security and processes hosting-related data under its privacy statement. The site adds no analytics scripts, account registration or contact form. Email sent to the public Gmail address is processed by the operator and the email service. Hosting and email records are not covered by the game's local rolling-log limit.

Data Security

The implementation bounds event sizes, event rate, the incoming queue and deduplication history. Provider errors are logged as generic descriptions rather than raw transport exceptions or authentication headers. Client secrets, access/refresh tokens, passwords, Authorization headers and cookies must not be placed in logs, event fields or support requests. Credentials are kept outside published files. These measures reduce risk; no system can guarantee absolute security.

User Choices and Requests

Send privacy, access, correction or deletion requests to kingdomslive.game@gmail.com. Requests are handled subject to applicable law and the data technically available. Session data may already be gone after the game closes. The operator may need information to identify the relevant data, but will not ask for your account password. KINGDOMS LIVE cannot erase independent copies held by a platform, streamer or audience. Contact the relevant service for data it controls.

Children's / Age Requirements

Users must meet the age, LIVE, Gift and account eligibility requirements imposed by TikTok or the applicable streaming platform. Regional platform rules apply. KINGDOMS LIVE does not independently verify a viewer's age or authorize participation that the platform prohibits.

International Processing

KINGDOMS LIVE is operated from Tajikistan. Authorized third-party LIVE platforms, hosting and email services may process data in other jurisdictions under their own policies. No specific server location is represented here. The operator must assess any required permissions and safeguards before connecting a production provider.

Changes to This Policy

This policy will be updated when relevant features or data practices change. The effective date identifies the version. Material changes will be communicated through the website or other appropriate means as required by applicable law.
