## Long description
KINGDOMS LIVE is a real-time interactive RED vs BLUE kingdom battle designed for TikTok LIVE.
Viewers can influence battles through supported LIVE interactions when an authorized event provider is connected.
Configured gift-triggered actions may summon Warriors, Archers, Mages, Knights, Heroes or a Dragon sequence.
Gift-spawned fighters display the viewer’s username. Units engage enemy fighters first, then advance toward
the opposing castle. Rounds restart automatically. A Russian operator panel supports local testing,
gift mapping, event diagnostics and Desktop or portrait presentation.

The local simulator is functional. The game is technically prepared for authorized TikTok LIVE event
integration; real production gifts are not currently connected.
