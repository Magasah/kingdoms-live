# CURRENT DRAFT STATE
KINGDOMS LIVE is a Windows Desktop game being prepared for an authorized LIVE Interactive Game integration.
According to the project owner, the TikTok for Developers app exists as a Draft with the name KINGDOMS LIVE
and Desktop platform. No unnecessary products or scopes are selected or claimed in this package.
This statement has not been independently verified inside the account.

No Login Kit, Display API, Share Kit, Content Posting API or Research API functionality is being claimed.
The current demonstration uses a local simulator. The game is not yet connected to authorized production LIVE events.
Keep this as draft preparation, not a claim of review readiness.

# FUTURE AUTHORIZED LIVE INTEGRATION
Once an authorized LIVE interface and its documentation are supplied, KINGDOMS LIVE will receive permitted
event data, normalize it, deduplicate gifts, resolve team membership and trigger configured gameplay actions.
The integration will use only capabilities required by that interface. Product/scope explanations must
then be rewritten from the actual approved integration and matched to a real demonstration.

Do not add unrelated products to bypass LIVE access requirements. A developer app credential alone
does not establish entitlement to receive LIVE Gifts.

# Review gate
The general [TikTok app review guidelines](https://developers.tiktok.com/docs/en/app-review-guidelines)
state that development/testing apps are not approved, require a functioning externally facing website,
and require visible, active privacy and terms links. This local package does not override that gate.
Keep the Draft until the requested review route, production readiness and evidence are confirmed.
