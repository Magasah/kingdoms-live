# Следующие действия — KINGDOMS LIVE
1. Откройте TikTok Developer → KINGDOMS LIVE → Production.
2. Заполните App Details по TIKTOK_PORTAL_FINAL_VALUES.md. Описание — 105 символов.
   Email: kingdomslive.game@gmail.com; страна: Tajikistan. Если поле требует юридическое имя,
   укажите настоящее имя оператора; не заменяйте его вымышленной компанией.
3. Откройте URL Properties / Verify Properties (названия могут отличаться в вашем интерфейсе).
4. Выберите URL prefix verification и укажите полный префикс https://magasah.github.io/kingdoms-live/.
5. Скачайте предоставленный TikTok signature-файл. Сохраните точное имя и содержимое.
6. Передайте этот файл для размещения либо положите его в Website/ по точному пути из портала,
   синхронизируйте с Publish/kingdoms-live/Website/, commit и push. Дождитесь Pages.
   Подробности: TIKTOK_URL_VERIFICATION.md. Нельзя угадывать путь или имя.
7. Откройте публичный HTTPS URL файла, сравните содержимое и вернитесь в TikTok → Verify.
8. Заполните заявку TikTok LIVE Interactive Games по LIVE_INTERACTIVE_REGISTRATION_FORM.md.
   Если портал требует демо до отправки, сначала выполните шаг 9. Отправку выполните самостоятельно.
9. Запишите демо по DEMO_VIDEO_SCRIPT.md и приложите его там, где требуется.
   Обозначьте локальный симулятор; не выдавайте его за авторизованный LIVE.
10. Дождитесь официальных или разрешённых инструкций и доступа к LIVE-интеграции.
    Передайте спецификацию интерфейса для подключения; не публикуйте секреты в чате или репозитории.

Не добавляйте Login Kit, Share Kit, Display API или Content Posting API без реальной необходимости.
URL verification не предоставляет доступ к LIVE и не означает одобрение приложения.

Источник маршрута URL prefix: [TikTok development configuration](https://developers.tiktok.com/docs/en/set-up-development-configuration).
