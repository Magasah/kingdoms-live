# Проверка URL в TikTok
1. Получите реальный verification/signature файл и точный URL в Developer Portal.
2. Поместите файл с неизменными именем и содержимым в Website/ по указанному относительному пути.
3. Синхронизируйте Website/ с выделенным репозиторием Publish/kingdoms-live/Website/.
4. Commit и push в main; дождитесь успешного GitHub Pages workflow.
5. Откройте фактический публичный URL файла и проверьте содержимое без авторизации.
6. Нажмите Verify в портале самостоятельно.

Не придумывайте имя файла и не публикуйте Client Secret вместо файла верификации.
GitHub project Pages размещает сайт под /kingdoms-live/. Если портал требует файл именно в корне
домена magasah.github.io/, а не под этим префиксом, потребуется доступ к корневому user-site
или другая подтверждённая стратегия. Не заявляйте, что проверка выполнена до реального ответа портала.
Файл портала ещё не предоставлен; структура сайта готова принять его.
