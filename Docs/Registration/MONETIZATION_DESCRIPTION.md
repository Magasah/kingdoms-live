# Entertainment interaction description
KINGDOMS LIVE is designed so supported LIVE Gifts can trigger entertainment/gameplay actions such as
summoning units or a special Dragon event. Virtual gifts and associated transactions remain governed
by the platform or authorized provider. Production gift access is pending.

The game does not promise cash prizes, gambling, betting, guaranteed financial rewards or investment returns.
A gift-triggered action does not guarantee a team victory. No real gift prices or revenue projections are asserted.
